# Установка готового списка из 1 817 студентов

В архив уже включены:

- 1 817 студентов;
- 100 учебных групп;
- 1 817 уникальных персональных кодов;
- закрытый SQL-файл для Supabase;
- конфиденциальный Excel для выдачи кодов;
- поиск и фильтр студентов в админ-панели.

## Важно

Папка `_private_student_import` содержит персональные данные. Она добавлена в
`.gitignore` и не должна загружаться в GitHub. Не используйте `git add -f` для
этой папки.

## Шаг 1. Обновление структуры базы

В Supabase откройте **SQL Editor → New query**.

Сначала выполните весь файл:

```text
supabase\teacher-survey-participants-update.sql
```

Ожидаемый результат:

```text
Success. No rows returned
```

## Шаг 2. Импорт всех студентов

Создайте второй запрос в SQL Editor и выполните весь файл:

```text
_private_student_import\01_IMPORT_STUDENTS_TO_SUPABASE.sql
```

Файл создаст недостающие группы и добавит всех студентов в текущий активный
период опроса. В базу загружаются только хеши кодов. Открытые коды в Supabase
не сохраняются.

Повторный запуск не создаёт дубликаты: записи обновляются по внутреннему номеру
студента.

## Шаг 3. Файл для выдачи кодов

Откройте:

```text
_private_student_import\02_КОДЫ_СТУДЕНТОВ_КОНФИДЕНЦИАЛЬНО.xlsx
```

В книге находятся:

- лист «Инструкция»;
- лист «Коды студентов»;
- лист «Сводка по группам».

Передавайте каждому студенту только код из его строки. Не отправляйте всю книгу
в общие группы.

## Шаг 4. Проверка

Запустите сайт:

```powershell
npm install
npm run dev
```

Откройте:

```text
http://localhost:3000/ru/admin/surveys/teacher
```

В реестре должно отображаться 1 817 студентов. Можно искать по Ф.И.О. и
фильтровать по группе.

После прохождения анкеты статус соответствующего студента изменится:

```text
Не прошёл → Прошёл
```

При этом ответы и комментарии остаются обезличенными.

## Шаг 5. GitHub и Netlify

Перед коммитом проверьте:

```powershell
git status --short
```

Папки `_private_student_import` в списке быть не должно.

Затем:

```powershell
git add -A
git commit -m "Добавлен реестр участников студенческого опроса"
git push origin main
```
