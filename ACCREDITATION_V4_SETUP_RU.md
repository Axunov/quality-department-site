# Аккредитация V4 — саморегистрация и два кабинета

1. Сначала должна быть выполнена `supabase/ACCREDITATION_V3_INSTALL.sql`.
2. Затем выполните `supabase/ACCREDITATION_V4_SELF_REGISTRATION.sql` в Supabase SQL Editor.
3. Пользователи регистрируются через `/ru/accreditation/login` (аналогично `/uz/...` и `/en/...`).
4. При регистрации пользователь указывает Ф.И.О., должность, ответственный блок и тип кабинета.
5. Новый профиль получает статус `pending`. Администратор открывает `/ru/admin/accreditation` и нажимает «Подтвердить профиль».
6. После подтверждения все индикаторы с выбранным `responsible_label` автоматически закрепляются за пользователем.
7. После входа в `/ru/accreditation/cabinet` пользователь выбирает комплексную или специальную аккредитацию.
8. В комплексной аккредитации сразу отображаются все индикаторы по главам; карточек-переходов больше нет.
9. В специальной аккредитации сверху выбирается образовательная программа, ниже сразу отображаются все индикаторы по главам.
10. Возле закреплённых за пользователем индикаторов появляются загрузка файла-ответа, версии документов и кнопка отправки на проверку.
11. Администратор проверяет документы в `/ru/admin/accreditation` и принимает либо возвращает на доработку.
12. Кабинет директора `/ru/accreditation/director` продолжает показывать сводный мониторинг обеих аккредитаций.
