# Пилот публичного помощника

Круглая кнопка помощника размещена на главной странице и на странице обращений на всех трёх языках. Без серверного ключа доступны чат, типовые вопросы, утверждённая справка и ссылки. Свободный текст сопоставляется с темой в браузере. Текст и история не уходят на сервер и не сохраняются после перезагрузки. При подключении модели сервер отправляет ей только код известной темы, язык и утверждённую публичную справку. Ссылки назначает приложение, рядом с пересказом доступен оригинал.

Чтобы включить ИИ, добавьте отдельный проектный ключ OpenAI как секрет `SITE_CHAT_OPENAI_API_KEY` в Netlify (Functions, если выбор доступен; отдельный ключ для Deploy Preview, если требуется проверка там). Ключ черновиков администрации не используется. После добавления выполните новый деплой. Без ключа, при исчерпании лимита или недоступности OpenAI показывается оригинал справки. `SITE_CHAT_ENABLED=0` скрывает блок после пересборки и останавливает вызовы модели.

Приложение ограничивает запросы к модели через существующий технический журнал, отдельный от квот администратора: ориентир до 5 за 10 минут на источник и 120 за скользящие 24 часа на проект при последовательных вызовах. Проверка счётчиков не атомарна. Перед включением внешнего API задайте бюджет и лимиты отдельного проекта OpenAI; статический режим не требует расходов на модель.
