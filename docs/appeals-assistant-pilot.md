# Пилот помощника по обращениям

На публичной странице доступны 15 справочных карточек на русском, узбекском и английском. Источники первой редакции: действующая форма отправки и проверки статуса, разделы «Контакты» и «Документы». Новые телефоны, сроки и правила рассмотрения не добавлены. Карточки обновляются в `src/lib/appealHelp.ts`; перед расширением базы их должен проверить редактор ОККО.

В админ-панели есть три шаблона: расписание, техническая проблема и предложение. Для других категорий и уже отвеченных либо закрытых обращений доступен ручной режим. Шаблон не отправляется, не меняет статус и не сохраняется отдельно: он только добавляется к тексту в текущем редакторе. Для проверки публикации чувствительных материалов используйте синтетические примеры.

Черновик с ИИ доступен только администраторам с MFA. К OpenAI уходят только код общей темы, язык, публичная справка и общий шаблон. Сервис не получает номер, идентификатор, оригинал обращения, ответы, контакты или файлы. Чтобы скрыть справку и черновики, установите `APPEALS_ASSISTANT_ENABLED=0` в среде сборки Netlify и запустите повторную публикацию. Исправления конфиденциальности при этом сохранятся.

Для новых анонимных обращений сервер отбрасывает Ф.И.О., группу и контакты; существующие записи не переписываются. Не более 30 проверок статуса за 10 минут для одного источника при обычной последовательной работе. В технический журнал не попадают номер и код. Почта через действующий Resend содержит только уведомление и ссылку в закрытую панель. Неиспользуемая необязательная отправка в Telegram удалена.

Перед пилотом проверьте три языка, анонимную и обычную форму, получение номера и кода, доступ к статусу и ответу, ручную отправку, внутренние заметки, смену обращения при открытом редакторе и отсутствие персональных данных в email. На рабочих данных не выполняйте пробную отправку без согласованного тестового процесса.

## Включение ИИ в Netlify

1. Создайте отдельный проект OpenAI API с биллингом. Установите лимит и оповещения для проекта.
2. Добавьте ключ проекта в настройки Netlify как секрет `APPEALS_OPENAI_API_KEY`, только для серверных функций Production. Не ставьте префикс `NEXT_PUBLIC_` и не сохраняйте ключ в репозитории.
3. Повторно опубликуйте сайт. Откройте типовое обращение в админ-панели и выберите «Подготовить черновик с ИИ», проверьте текст и источники. Для проверки используйте согласованные тестовые данные. Черновик сам не публикуется.
4. Для отключения только модели установите `APPEALS_AI_ENABLED=0` и повторно опубликуйте. Справка, шаблоны и ручной ответ останутся доступны.

До ввода ключа статический пилот работает; запрос к модели возвращает сообщение о недоступности. Приложение отмечает попытки в существующем техническом журнале с отдельными HMAC-областями (3 за минуту на администратора, 1 000 в месяц на сайт при последовательной работе). Это не атомарный финансовый лимит; отдельно ограничьте расходы на стороне аккаунта. Запросы не сохраняются в истории Responses API (`store: false`); это не отменяет обычных правил хранения провайдера для мониторинга злоупотреблений.
