# Автоматический импорт преподавателей и дисциплин

В пакет уже включён список, извлечённый из предоставленного расписания:

- 55 учебных групп;
- 103 преподавателя;
- 363 привязки «группа — преподаватель»;
- дисциплины объединены, если один преподаватель ведёт в группе несколько предметов.

## Как установить

1. Откройте Supabase проекта.
2. Перейдите в **SQL Editor**.
3. Нажмите **New query**.
4. В VS Code откройте файл:

   `supabase/teacher-survey-schedule-import.sql`

5. Скопируйте всё содержимое файла (`Ctrl+A`, затем `Ctrl+C`).
6. Вставьте SQL-код в редактор Supabase (`Ctrl+V`).
7. Нажмите **Run**.

После выполнения внизу появится таблица с группами и количеством
преподавателей. Скрипт заменяет только привязки преподавателей для 55 групп,
которые присутствуют в расписании. Студенты, коды и ответы не удаляются.

## Проверка

1. Запустите сайт командой `npm run dev`.
2. Откройте `/ru/admin/surveys/teacher`.
3. В блоке «Закрепление за группой» должно отображаться количество назначений.
4. Откройте `/ru/student-survey`.
5. Введите персональный код студента из конфиденциального Excel-файла.
6. Выберите группу этого студента и нажмите «Загрузить преподавателей».

Контрольный перечень находится в файле:

`supabase/teacher-survey-schedule-review.csv`

В исходном расписании для преподавателя «Анвар» фамилия и отчество заменены
точками. Поэтому в системе он отмечен как
«Анвар (Ф.И.О. в расписании указано не полностью)». После уточнения данных это
имя можно изменить в админ-панели или SQL.
