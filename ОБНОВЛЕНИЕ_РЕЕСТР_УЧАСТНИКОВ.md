# Обновление: контроль участия без раскрытия ответов

## Как теперь работает система

1. Администратор выбирает учебную группу.
2. Вставляет список студентов: одно Ф.И.О. в каждой строке.
3. Система создаёт для каждого студента отдельный случайный код.
4. Администратор передаёт студенту его код.
5. Студент вводит только код и не указывает Ф.И.О.
6. После отправки анкеты в закрытом реестре появляется статус «Прошёл».
7. Оценки и комментарии сохраняются отдельно, без Ф.И.О. и без кода.

Администратор может увидеть, кто участвовал, но не может определить, какие
ответы и комментарии принадлежат конкретному студенту.

## Шаг 1. Обновите базу Supabase

1. Откройте Supabase → SQL Editor.
2. Создайте новый запрос.
3. Откройте в VS Code файл:

```text
supabase\teacher-survey-participants-update.sql
```

4. Скопируйте весь файл в SQL Editor.
5. Нажмите **Run**.
6. Ожидаемый результат: **Success. No rows returned**.

Этот файл предназначен для базы, где предыдущая версия опроса уже установлена.
Старые ответы и настройки он не удаляет.

## Шаг 2. Запустите новую версию сайта

В терминале VS Code:

```powershell
npm install
npm run dev
```

Откройте:

```text
http://localhost:3000/ru/admin/surveys/teacher
```

## Шаг 3. Создайте персональные коды

1. Выберите группу в блоке закрепления преподавателей.
2. В блоке «Персональные анонимные коды» вставьте список:

```text
Абдуллаев Азиз Акмалович
Иванова Мария Сергеевна
Каримов Бехруз Бахтиёрович
```

3. Нажмите «Создать и скачать персональные коды».
4. Сохраните скачанный CSV.
5. Передайте каждому студенту только код из его строки.

## Шаг 4. Проверьте реестр

После прохождения тестовой анкеты обновите админ-страницу. В разделе
«Реестр участия студентов» возле соответствующего Ф.И.О. статус изменится:

```text
Не прошёл → Прошёл
```

Кнопка «Скачать реестр» выгружает в CSV только список участников и статусы.
Кнопка «Скачать результаты CSV» выгружает обезличенные ответы.

## Важно о старых кодах

Коды, созданные в предыдущей версии без списка Ф.И.О., останутся рабочими, но
будут показаны как «Без имени (старый код)». Определить владельцев этих кодов
задним числом невозможно. Для нового опроса создайте новые персональные коды.
