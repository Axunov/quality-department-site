# Личный кабинет студента — установка обновления

## Что изменено

- Student ID вводится только на отдельной странице входа.
- После входа студент попадает в личный кабинет.
- В кабинете отображаются Ф.И.О., учебная группа и доступные опросы.
- Опрос запускается кнопкой «Пройти опрос».
- На странице анкеты не отображаются Student ID, Ф.И.О., коды доступа,
  токены или номер квитанции.
- После отправки отображается только сообщение об успешном завершении.
- Администратор продолжает видеть реестр «Прошёл / Не прошёл».
- Ответы по-прежнему не связаны с Ф.И.О. и Student ID.

## 1. Обновление Supabase

1. Откройте проект в Supabase.
2. Перейдите в `SQL Editor`.
3. Нажмите `New query`.
4. Откройте файл:

   `supabase/student-portal-upgrade.sql`

5. Скопируйте весь код файла в SQL Editor.
6. Нажмите `Run`.
7. В нижней таблице должны появиться три значения `true`:

   - `portal_login_ready`;
   - `portal_profile_ready`;
   - `portal_survey_ready`.

Повторно импортировать студентов, группы, преподавателей и расписание не нужно.

## 2. Локальная проверка

В терминале VS Code:

```powershell
npm install
npm run dev
```

Откройте:

`http://localhost:3000/ru/student/login`

Проверьте:

1. Вход по неиспользованному Student ID.
2. Отображение Ф.И.О. и группы в личном кабинете.
3. Карточку опроса со статусом «Доступен для прохождения».
4. Переход по кнопке «Пройти опрос».
5. Отсутствие Student ID, Ф.И.О. и технических кодов на странице вопросов.
6. Отправку анкеты.
7. Статус «Опрос завершён» после возвращения в кабинет.

## 3. Размещение через GitHub и Netlify

Перенесите содержимое обновлённого проекта в папку GitHub-копии, исключая:

- `.env.local`;
- `node_modules`;
- `.next`;
- `.netlify`;
- `_private_student_import`.

Затем:

```powershell
git add .
git commit -m "Add student portal and anonymous survey flow"
git push origin main
```

Netlify автоматически соберёт и опубликует новую версию.

После статуса `Published` откройте:

`https://qualitydepartment.netlify.app/ru/student/login`

и обновите страницу сочетанием `Ctrl + F5`.

## Важно

Личный кабинет и анонимные ответы технически разделены:

1. кабинет подтверждает личность и показывает статус участия;
2. при запуске опроса создаётся отдельный анонимный сеанс;
3. ответы записываются без Ф.И.О. и Student ID;
4. после отправки анонимный сеанс удаляется;
5. в реестре участия остаётся только отметка о завершении.
