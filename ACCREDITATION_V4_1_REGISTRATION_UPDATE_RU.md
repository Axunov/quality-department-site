# Обновление регистрации V4.1

- Поле «Должность» теперь только выпадающий список.
- Ручной ввод должности удалён.
- Повторяющиеся должности объединяются автоматически.
- Составные значения ответственных разделяются на отдельные должности.
- Для директора должность устанавливается автоматически.
- Выбранная должность одновременно используется для закрепления индикаторов.
