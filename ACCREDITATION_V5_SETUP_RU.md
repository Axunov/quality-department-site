# Accreditation V5

1. Выполните `supabase/ACCREDITATION_V5_AUTO_ASSIGN_AND_EMPLOYEE_ADMIN.sql`.
2. Если нужно полностью очистить тестовые регистрации, один раз выполните `supabase/ACCREDITATION_V5_RESET_REGISTRATIONS.sql`.
3. Перезапустите сайт.

Изменения:
- один канонический список должностей вместо дублирования RU/UZ;
- название должности показывается на языке интерфейса;
- после регистрации одна должность связывает сотрудника с индикаторами сразу во всех трёх проектах: комплексная + две специальные программы;
- пока профиль не подтверждён администратором, загрузка материалов запрещена;
- после подтверждения назначение сохраняется автоматически;
- в админ-панели появился список зарегистрированных сотрудников;
- сотрудника можно включать/отключать, менять должность и сбрасывать доступ.
