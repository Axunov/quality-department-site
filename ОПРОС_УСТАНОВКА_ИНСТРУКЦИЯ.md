# Установка опроса «Преподаватель глазами студента»

## Что уже добавлено

- публичная анкета на русском, узбекском и английском языках;
- 8 оценочных вопросов для каждого преподавателя;
- варианты 5–1 и «Не могу оценить»;
- вопрос о ситуациях, требующих внимания администрации;
- необязательный комментарий;
- два общих вопроса после оценки всех преподавателей;
- анонимное хранение результатов;
- одноразовые коды для защиты от повторного прохождения;
- управление группами и преподавателями;
- просмотр статистики и выгрузка CSV для Excel.

## Шаг 1. Откройте проект в VS Code

1. Распакуйте архив в новую папку, например:
   `C:\Sites\quality-site-survey`
2. Запустите VS Code.
3. Выберите **File → Open Folder**.
4. Откройте папку `C:\Sites\quality-site-survey`.
5. Откройте терминал: **Terminal → New Terminal**.
6. Выполните:

```powershell
npm install
```

## Шаг 2. Создайте таблицы в Supabase

1. Откройте сайт [Supabase](https://supabase.com/dashboard).
2. Выберите проект, который подключён к сайту.
3. В левом меню откройте **SQL Editor**.
4. Нажмите **New query**.
5. В VS Code откройте файл:
   `supabase/teacher-survey.sql`
6. Скопируйте весь текст файла.
7. Вставьте его в SQL Editor.
8. Нажмите **Run**.
9. Должно появиться сообщение об успешном выполнении без красной ошибки.

Не запускайте файл повторно после начала реального опроса без необходимости.

## Шаг 3. Проверьте локально

В терминале VS Code выполните:

```powershell
npm run dev
```

Откройте:

- сайт: `http://localhost:3000/ru`
- анкета: `http://localhost:3000/ru/surveys/teacher`
- админ-раздел: `http://localhost:3000/ru/admin/surveys/teacher`

Для входа используйте существующую учётную запись администратора сайта.

## Шаг 4. Подготовьте опрос в админ-панели

Откройте **Админ-панель → Опрос студентов** и выполните действия по порядку:

1. Добавьте все учебные группы.
2. Добавьте Ф.И.О. всех преподавателей.
3. Выберите группу и преподавателя.
4. Укажите дисциплину.
5. Нажмите **Закрепить преподавателя**.
6. Повторите для всех преподавателей каждой группы.
7. Выберите нужную группу.
8. Укажите число студентов.
9. Нажмите **Создать и скачать коды**.

Будет скачан CSV-файл с одноразовыми кодами. Каждый студент получает один код.
Полный код хранится только в скачанном файле. В базе сохраняется необратимый
SHA-256 хеш, поэтому по базе нельзя связать конкретный код с ответами.

## Шаг 5. Проверка полного сценария

1. Откройте страницу анкеты в режиме инкогнито.
2. Введите один тестовый код.
3. Выберите соответствующую группу.
4. Ответьте на все вопросы.
5. Отправьте анкету.
6. Попробуйте использовать тот же код повторно — система должна отказать.
7. Вернитесь в админ-панель.
8. Убедитесь, что счётчик анкет увеличился.
9. Нажмите **Скачать результаты CSV**.
10. Откройте CSV в Microsoft Excel.

## Шаг 6. Отправьте обновление на GitHub

В терминале, находясь в папке проекта:

```powershell
git status
git add -A
git commit -m "Добавлен анонимный опрос студентов"
git push origin main
```

После `git push` Netlify автоматически начнёт сборку.

## Шаг 7. Проверьте Netlify

1. Откройте [Netlify](https://app.netlify.com).
2. Выберите проект **qualitydepartment**.
3. Откройте раздел **Deploys**.
4. Дождитесь статуса **Published**.
5. Проверьте:
   `https://qualitydepartment.netlify.app/ru/surveys/teacher`

## Конфиденциальность

Анкета не собирает Ф.И.О. студента, номер телефона, email, Telegram ID или IP
в таблицы результатов. Администратор видит группу, оценки, комментарии и дату,
но не может определить автора конкретного ответа.

Не публикуйте полный файл с одноразовыми кодами на сайте или в общей группе.
Передавайте студентам коды индивидуально либо разрезанными карточками.
