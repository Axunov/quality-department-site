# Локальная проверка обновления аккредитации V5.8

## 1. Запуск сайта локально

1. Распакуйте архив.
2. Откройте папку проекта в PowerShell или терминале VS Code.
3. Сохраните действующие переменные Supabase в файле `.env.local`.
4. Выполните:

```powershell
npm install
npm run dev
```

5. Откройте `http://localhost:3000/ru/accreditation`.

## 2. Что проверить

- В разделе «Аккредитация» отображается кнопка входа в систему.
- При регистрации доступны шесть отдельных кафедр на русском, узбекском и английском языках.
- В админ-панели можно последовательно создавать аккаунты разных сотрудников.
- Возвращённый на доработку ответ можно загрузить повторно; новая загрузка сохраняется как следующая версия.
- Обычный сотрудник не видит общую статистику.
- Директор видит статистику комплексной и специальной аккредитации.
- Администратор видит закрытую статистику в разделе администрирования аккредитации.
- Прямая ссылка на кабинет директора недоступна обычному сотруднику.

## 3. Обязательное обновление Supabase

Перед окончательной публикацией откройте Supabase → SQL Editor и выполните файл:

`supabase/ACCREDITATION_V5_8_PRIVATE_STATS_AND_ROLES.sql`

Он закрывает статистику и доказательные файлы на уровне базы данных, усиливает проверку роли директора и добавляет поддержку отдельных должностей заведующих кафедрами.

## 4. Проверка перед публикацией

```powershell
npm run lint -- --quiet
npm run build
```

После успешной проверки проект можно отправить в основную ветку GitHub. Netlify автоматически соберёт обновлённую версию, если репозиторий уже подключён к сайту.
