# Установка модуля управления аккредитацией

## 1. Применить SQL-схему

Откройте Supabase → SQL Editor и выполните файл:

`supabase/accreditation_workspace.sql`

Схема создаёт таблицы проектов, подразделений, рабочих групп, индикаторов, документов, проверок, комментариев и истории действий, а также закрытое хранилище `accreditation-evidence`.

## 2. Создать пользователей

Пользователи создаются в Supabase Authentication. После создания необходимо назначить им роли в таблице `accreditation_memberships`:

- `department_head` — руководитель подразделения;
- `quality_office` — отдел качества;
- `administrator` — администратор;
- `director` — директор.

## 3. Проверить маршруты

- `/ru/accreditation`
- `/ru/accreditation/institutional`
- `/ru/accreditation/self-assessment`
- `/ru/accreditation/indicators`
- `/ru/accreditation/documents`
- `/ru/accreditation/working-groups`

Маршруты также доступны для `/uz` и `/en`.

## 4. Текущий этап

Интерфейс страниц и база данных подготовлены. До подключения форм редактирования страницы показывают демонстрационные показатели. Следующий этап — загрузка реальных 272 индикаторов, создание кабинетов и подключение действий загрузки, проверки, возврата и утверждения.
