# Модуль комплексной и специальной аккредитации

## Что включено
- Комплексная государственная аккредитация: 269 индикаторов.
- Специальная государственная аккредитация: 94 индикатора отдельно для каждой программы:
  - Программная инженерия / Dasturiy ta’minot muhandisligi / Software Engineering.
  - Приборостроение (биомедицинская инженерия) / Asboblar muhandisligi (biomedical muhandislik) / Instrumentation Engineering (Biomedical Engineering).
- Интерфейс специальной аккредитации RU / UZ / EN.
- Кабинет руководителя подразделения с загрузкой файла-ответа и отправкой на проверку.
- Админ-панель для создания учетных записей, назначения индикаторов, принятия и возврата материалов на доработку.
- Кабинет директора с мониторингом всех трех потоков аккредитации.
- Единый расчет прогресса: 0% → 25% после загрузки → 75% на проверке → 100% после принятия; при возврате — 50%.

## Установка базы
1. Откройте Supabase → SQL Editor → New query.
2. Выполните целиком файл `supabase/ACCREDITATION_V3_INSTALL.sql`.
3. Убедитесь, что итоговая строка показывает 3 проекта и 457 индикаторов.
4. В Netlify должны быть заданы `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`.

## Работа администратора
1. Войдите в существующую админ-панель.
2. Откройте `/ru/admin/accreditation` (также доступны `/uz/...` и `/en/...`).
3. Создайте учетную запись руководителя/сотрудника отдела качества/директора.
4. Для руководителя выберите его учетную запись и ответственное подразделение из списка, затем нажмите Assign all.
5. Материалы со статусом «На проверке» появятся в нижнем блоке. Администратор может принять их или вернуть на доработку с комментарием.

## Кабинеты
- `/ru/accreditation/login` — вход руководителей и директора.
- `/ru/accreditation/cabinet` — кабинет ответственного руководителя.
- `/ru/accreditation/director` — кабинет директора.
- `/ru/admin/accreditation` — рабочая панель администратора/отдела качества.

## Основные страницы
- `/ru/accreditation` — единый центр мониторинга.
- `/ru/accreditation/complex` — комплексная аккредитация.
- `/ru/accreditation/special` — специальная аккредитация.
- `/ru/accreditation/special/indicators?program=software-engineering`
- `/ru/accreditation/special/indicators?program=biomedical-instrumentation`

Для узбекского и английского языков замените `/ru/` на `/uz/` или `/en/`.
