# Анонимный опрос с входом по Student ID

## Что изменено

- одна общая ссылка для всех студентов;
- вход по постоянному идентификатору `STU-0001`;
- группа определяется автоматически;
- после проверки ID создаётся анонимная сессия на 2 часа;
- Ф.И.О. и Student ID не передаются вместе с ответами;
- после отправки техническая связь сессии со студентом удаляется;
- в реестре участия сохраняется только статус и дата без точного времени;
- студент получает квитанцию о завершении;
- повторное прохождение блокируется.

## Установка базы данных

Предыдущие SQL-импорты студентов и расписания должны быть уже выполнены.

1. Откройте Supabase проекта.
2. Перейдите в **SQL Editor**.
3. Нажмите **New query**.
4. В VS Code откройте:

   `supabase/teacher-survey-student-id-login.sql`

5. Скопируйте всё содержимое файла.
6. Вставьте его в новый запрос Supabase.
7. Убедитесь, что выделен весь код либо ничего не выделено.
8. Нажмите **Run** один раз.

В результате должны появиться два значения `true`:

```text
student_id_login_ready | anonymous_submit_ready
true                   | true
```

## Локальная проверка

1. Выполните:

   ```powershell
   npm install
   npm run dev
   ```

2. Откройте:

   `http://localhost:3000/ru/surveys/teacher`

3. Для первого теста используйте ID из конфиденциального Excel:

   `_private_student_import/02_КОДЫ_СТУДЕНТОВ_КОНФИДЕНЦИАЛЬНО.xlsx`

4. На листе «Коды студентов» возьмите значение из столбца `ID`, например
   `STU-0001`.
5. После входа группа и преподаватели должны загрузиться автоматически.
6. Заполните анкету и отправьте её.
7. Сохраните показанную квитанцию.
8. Откройте админ-панель:

   `http://localhost:3000/ru/admin/surveys/teacher`

9. У студента должен появиться статус «Прошёл», а новая анкета должна
   появиться в результатах без Ф.И.О. и Student ID.

## Важно

Идентификаторы `STU-0001`, `STU-0002` и далее последовательные. Они позволяют
контролировать однократность участия, но не являются паролями. Не публикуйте
полный реестр соответствий «ID — Ф.И.О.» в открытом доступе.

Файл из папки `_private_student_import` нельзя загружать на GitHub. Папка уже
добавлена в `.gitignore`.
